Physics-informed neural networks (PINNs) and Kolmogorov–Arnold networks (KANs) provide flexible representations for partial differential equations (PDEs), but their optimization cost and sensitivity to problem structure can limit practical use. We propose the Extensible Least-Squares Kolmogorov–Arnold Network (ELSKAN), which combines fixed hidden features with a trainable linear output and assembles PDE, boundary, and initial constraints into a regularized least-squares system. 
For linear PDEs with linear constraints, training requires one linear-system solve. For nonlinear PDEs, an outer Newton-type iteration repeatedly evaluates residuals and Jacobians and solves regularized linearized subproblems.
Three variants adapt the feature space to problem structure: S-LSKAN combines Chebyshev branches for mixed-frequency behavior, H-LSKAN combines Diff-Sigmoid and Gaussian radial basis functions for localized features, and DP-LSKAN couples subdomains while excluding physical crack faces from artificial continuity constraints. 
On eight linear benchmarks, the main reported configurations yield lower errors than the selected baselines in seven cases, with shorter reported solution times. PIKAN is more accurate on transient advection-diffusion. Ten-seed results characterize initialization sensitivity for all eight linear cases, and three manufactured nonlinear tests demonstrate the iterative extension.
